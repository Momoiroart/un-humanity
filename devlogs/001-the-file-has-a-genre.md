# Devlog 001 — The File Has a Genre

`FILE UH-000 · DEVLOG 001 · 2026-07-30 · pre-production`

Last entry opened the file without saying what kind of game it is. This one
makes the call. Three decisions locked: **genre, power system, first case.**

## 1. Genre — investigation first, then turn-based combat

UN-HUMANITY is an **investigation-driven RPG with turn-based combat.** The
core is the Sight loop: walk a normal-looking place, find what's wrong, decide
what it is. Fighting is what happens when the thing you found decides it
doesn't want to be classified.

Why turn-based, and not action? Because of what these enemies *are.* An
Un-Humanity entity is defined by **cheating** — it skips the cost that any
human power has to pay. That idea only lands if the game has visible rules to
break. In a turn-based system there's a turn order, an action cost, a
resource bar — so when a monster takes your turn, or acts for free, or makes
the turn counter stop mattering, you *see* the violation. It reads as wrong,
not as a bigger number.

So the fights aren't about out-damaging anything. You work out which rule the
thing is breaking, and you make it pay that rule back. First fight you can't
brute-force is the one that teaches you how the whole game thinks.

## 2. Power system — you learn from people, in your cover life

The protagonist's powers come from **human crafts** — a writer can write
things true, but only once people believe them; a painter can paint things
real, but only what their skill can actually render. Every power costs exactly
what the real craft costs. That's the line Un-Humanity refuses to obey.

The decision: you **learn each craft from a mentor you meet in your cover
life.** The double life isn't set dressing — the people you keep up with
*are* your skill tree. Maintaining a relationship and unlocking a power are
the same action. Nobody teaches you for free either.

## 3. First case — FILE UH-001, "The Bus Stop Waiter"

The field note from the last entry wasn't flavor. It's the first real case,
and it's the vertical slice:

> "A man has been waiting at the bus stop since this morning."
>
> "Nothing has been waiting there since 1974. It knows you noticed."

One location, one anomaly, one full loop — tip to resolution, playable end to
end. It's designed. Now it gets built.

## Next

Combat core first — it's the riskiest unknown, so it goes in an empty scene
before anything gets dressed. Turn queue, action costs, and the hooks that let
an enemy break them. Then the Sight toggle, then the case log, then stitch the
slice together.
